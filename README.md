# 🎵 Music Chatroom 🎵

A web application built for chatting about and sharing music recommendations with other users.

## Getting started
1. Navigate to the deployment: [https://lechoi1.github.io/music-chat-app/#/](https://lechoi1.github.io/music-chat-app/#/)
2. Click "Log In"
3. Log in to [Graffiti](https://graffiti.garden/) by creating a new Graffiti identity or using an existing one.
4. Enjoy!

## Features
* **Real-Time and Persistent Messaging**: Create custom chats, edit and delete messages, and tag music messages with their genres.
* **Music Exploration & Search**: Discover new music chatrooms on the "Explore" page, and search for specific messages across all chats on the "Search" page.
* **Custom User Profiles**: Set custom display name.
* **Single-page Application (SPA) with Components**: Allows seamless navigation between home, chat, search, explore, and profile views without full page reloads.
